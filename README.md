# HoloKinetic Gesture Lab

A browser-based computer-vision playground that you control with your bare hands through a webcam. It has two modes in one React app:

- **HoloKinetic Lab**: a two-hand 3D physics scene (Three.js). Catch, hold, toss and scale a 3D object between your hands, with sparks, an energy tether between the hands and synthesized sound effects.
- **ChronoGrip**: a time scrubber. Pinch, sweep or open your palm to scrub a time-lapse video forward and backward in real time.

Everything runs locally in the browser. No server, no GPU cluster and no uploads: your camera feed never leaves your machine.

## How it works

- **Hand tracking:** Google **MediaPipe Hands** (a pre-trained model) returns 21 landmarks per hand. I did not train this model. The work in this project is the logic built on top of its output.
- **ChronoGrip maths:** thumb-tip to index-tip Euclidean distance, normalised to 0-1, smoothed with a linear-interpolation filter, then bound to `video.currentTime`.
- **HoloKinetic Lab:** hand landmarks are projected into 3D world coordinates. A small kinetic engine handles catching (a magnetic catch radius), holding, throwing (from tracked hand velocity), wall rebounds, gentle gravity and two-handed scaling.
- **Rendering:** React 19 and Three.js, with sound effects generated by the Web Audio API.

## Reliability design

Hand tracking is noisy, so the raw output is cleaned up before it drives anything (`src/lib/handTracker.js`, unit-tested):

- **Smoothing:** palm positions use an exponential filter to remove jitter.
- **Dropout grace:** a hand that disappears for a frame or two stays alive for about 220 ms instead of dropping the object.
- **Pinch hysteresis:** separate enter and exit thresholds stop the pinch flickering on and off.
- **Velocity estimate:** throws use a smoothed velocity in world units per second, so a throw feels the same at any camera frame rate.
- **Frame-rate independent physics:** motion is scaled by elapsed time, so 60 Hz and 120 Hz displays behave the same.
- **Adaptive quality:** if the full hand model cannot keep up, it switches to the lite model automatically. The HUD shows live FPS.
- **Clear errors:** camera permission or load failures show a message instead of failing silently.

## Run it

```bash
npm install
npm run dev
```

Open the local URL that Vite prints and allow camera access. Raise one or both hands in front of the camera.

## Tests

```bash
npm test
```

The tracker's smoothing, dropout, pinch and left/right assignment logic is covered by Node's built-in test runner.

## Notes

- The repository includes five short sample clips for ChronoGrip. You can also upload your own video from the app.
- Inspired by gesture-controlled projection demos. This is a learning and portfolio project, not a production product.

## Stack

React 19, Vite, Three.js, MediaPipe Hands, Web Audio API.
