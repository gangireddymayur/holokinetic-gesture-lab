Control a 3D scene and a video timeline with your bare hands, using only a webcam and your browser.

Everything runs **locally in the browser**. There is no server, and your camera feed never leaves your machine.

## Two modes in one app

### HoloKinetic Lab: two-hand 3D physics
A Three.js scene where your hands act as catchers, throwers and scalers.

- **Catch:** bring a hand near the object and it snaps magnetically to your palm.
- **Carry and throw:** move your hand to carry it, flick to throw it. Throw speed comes from your hand's smoothed velocity.
- **Bounce or catch:** a thrown object bounces off an open palm, or you pinch to catch it.
- **Two-handed scaling:** hold it with both hands, then spread or push your hands to resize it.
- **Arsenal:** five objects (Quantum Basketball, Tesseract Core, Arc Reactor, Vibranium Crystal, Quantum Rings), with sparks, an energy tether and synthesized sound effects.
- **AR overlay:** optionally blend your camera feed behind the scene.

### ChronoGrip: gesture time scrubber
Scrub a time-lapse video forward and backward in real time.

- **Pinch:** thumb-to-index distance sets the playback position.
- **Sweep:** move your hand left and right across the camera.
- **Palm openness:** open your hand to advance, close it to rewind.
- Upload your own video, tune smoothing and sensitivity, and lock the gesture in place.

## Controls

| Mode | Key | Action |
|---|---|---|
| HoloKinetic Lab | `1` / `2` | Snap the object to your left / right hand |

| HoloKinetic Lab | `R` | Reset the object |

| ChronoGrip | `H` | Show or hide the camera window |
| ChronoGrip | `F` | Fullscreen |

## How it works

1. **Hand landmarks:** Google's **MediaPipe Hands** (a pre-trained model, not trained here) returns 21 landmarks per hand from each camera frame.
2. **Stabilisation:** `src/lib/handTracker.js` turns that noisy output into stable hand state (below).
3. **Gesture maths:**
   - ChronoGrip normalises the thumb-tip to index-tip distance and smooths it:
     `progress = clamp((dist - min) / (max - min), 0, 1)`, then `smoothed += (progress - smoothed) * alpha`, bound to `video.currentTime`.
   - HoloKinetic Lab projects the palm landmark into the 3D scene's world coordinates and runs a small catch, carry, throw and bounce state machine on top.
4. **Rendering:** React 19 and Three.js, with sound effects generated by the Web Audio API.

### Making tracking reliable

Raw hand tracking jitters, drops frames and can swap left and right. The tracker handles that, and it is unit-tested:

| Problem | Fix |
|---|---|
| Jittery positions | Exponential smoothing of the palm position |
| Hand missing for a frame or two | Hand stays alive for about 220 ms before the object is released |
| Pinch flickering at the threshold | Separate enter and exit thresholds (hysteresis) |
| Throws feel inconsistent | Smoothed velocity in world units per second, independent of camera frame rate |
| Left/right labels swap | When two hands share a label, they are assigned by screen position |
| Physics differs on 60 Hz and 120 Hz screens | Motion scaled by elapsed time |
| Object stuck after a throw | Once it settles it becomes catchable by an open hand again |
| Slow machines | Falls back to the lite hand model when the full one cannot keep up; the HUD shows live FPS |
| Camera or load failures | Clear on-screen messages instead of silent failure |

## Run it

Requires Node.js 18+ and a webcam.

```bash
git clone https://github.com/gangireddymayur/holokinetic-gesture-lab.git
cd holokinetic-gesture-lab
npm install
npm run dev
```

Open the local URL that Vite prints and allow camera access. Raise one or both hands in front of the camera.

```bash
npm test        # unit tests for the hand tracker
npm run build   # production build
```

## Project structure

```
src/
  App.jsx                          mode switcher
  lib/handTracker.js               smoothing, dropout grace, pinch hysteresis, velocity
  components/HoloKineticLab.jsx    two-hand 3D physics lab (Three.js)
  components/ProjectionInterface.jsx  ChronoGrip time scrubber
test/handTracker.test.js           unit tests (node:test)
public/videos/                     short sample clips for ChronoGrip
```

## Limitations

- Hand tracking uses a **pre-trained** model. This project does not train or evaluate a model.
- The MediaPipe scripts and model files are loaded from a CDN, so an internet connection is needed on first load.
- Gesture feel depends on lighting, camera quality and distance from the camera. The thresholds are tuned by hand.
- Tested in desktop Chrome. Other browsers may behave differently.
- The included sample clips are for demonstration. If you fork this project, use your own footage.

## Ideas for next steps
